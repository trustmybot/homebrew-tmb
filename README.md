# homebrew-tmb

Homebrew tap for [tmb](https://github.com/trustmybot/tmb-releases), a harness for coding agents.

```sh
brew install trustmybot/tmb/tmb-dev   # dev channel
```

The `tmb` (stable) and `tmb-rc` formulae appear here with the first stable and rc releases. tmb also updates itself from its channel between sessions.

The formulae are written by tmb's release workflow; do not edit them by hand.
